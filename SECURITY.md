# Security policy

## Supported versions

Until `v1.0.0`, only the latest minor release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through
[GitHub security advisories](https://github.com/yaboylino/gonestly/security/advisories/new)
instead.

Include what you found, how to reproduce it and the impact you expect. You will get a response
within five working days. Once a fix is released, the advisory is published and you are credited,
unless you prefer to stay anonymous.
